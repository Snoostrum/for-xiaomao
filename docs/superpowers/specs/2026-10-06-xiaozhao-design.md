# 小灶 · 设计文档

> 给一位不太了解 AI 的朋友做的个人工具:**PDF 课件问答 + 资料批量下载**。
> 他人在澳门:网络无限制(境外服务直连,不需要代理);**设备是 Mac**。工具跑在他自己的电脑上。
> 项目目录 `xiaozhao`(界面显示名「小灶」)。目录名用英文,避开中文路径在打包工具链里的偶发问题。
> 状态:M1 骨架与 §4 工程已验收(2026-10-06);**2026-10-07 本体修订为 agent 形态**(本次修订待用户复核)。

**修订说明(2026-10-07)**:原设计把课件和下载各做成一条固定流程(字数门槛判扫描页、引擎分派表、整本语料注入……)。用户拍板纠正——**"最开始的需求就是想要做一个像你这样的 Agent,但主要任务是解析课件和爬取一些资料,搭配 llm 是刚需"**。即:小灶本体就该是一个 **agent 循环**,课件解析和资料抓取是它手里的**工具**,LLM 是转这个循环的**大脑**,不是外挂的一颗键。原则:**判断交给模型,体力活留给代码**;不再为想象中的资料预先搭流程。已实施的 M2 解析管线拆成零件归工具复用:文字层抽取、视觉转写、逐页缓存、记账全部保留;整本批处理与「解析」入口撤销。

## 0. 背景、目标与边界

**朋友画像**:不太了解 AI,但电脑上"会折腾"。**人在澳门**——网络无限制(境外服务直连,不需要代理);**设备是 Mac**。

**两大用途**:

- **A 课件助手**:把 PDF 课件丢给小灶,提问、总结。课件多为中文 PPT 导出,可能含扫描页。
- **B 下载管家**:批量获取高清资料 = 高清图片/素材 + 视频/录播课。

**形态(2026-10-07 定)**:小灶是一个**像 Claude Code 那样的 agent**——朋友说人话,小灶自己决定下一步:翻哪页、要不要看一眼扫描页、这条链接该用什么去下、什么时候停下问人。LLM 是刚需(循环的大脑),工具是它的手脚。

**成功标准**:

1. 朋友的 Mac 上一次装成、一次配通(Windows 为第二目标:你的开发机 + 自测)。
2. 课件问答:小灶自己找页、自己决定看不看图,页码引用正确;同一个课件反复提问,看过的页不重复花钱。
3. 下载只读他本来就有权访问的公开内容;触线即停。
4. 费用可见可控:**免费额度起步,付费按需再加**(以实测为准);每次提问花了多少次调用、多少 token,看得见。

**分工**(本项目特例):Claude 全权编写,用户验收。代码需可读、带解释,用户能看懂结构并自行修改。

**明确的边界(不做)**:

- 不绕付费墙、验证码、DRM、加密封装;不抓个人隐私数据。
- 网盘分享不做自动化,只识别并提示用官方客户端。
- 下载范围含境外站点(他的网络可直连;逐站实测,见 §3)。
- 不做多用户、在线服务、手机端;不做"分享/导出"功能。
- 不为想象中的站点预先搭功能:工具集够不着的地方,小灶如实说"拿不下",真撞见了再补工具。

**诚实的定位**:他网络无墙,值得用的现成产品不少——**但能否覆盖澳门要逐个确认**(已核实:Google 与 Anthropic 的官方 API 地区名单都不含澳门)。本工具的价值 = **下载→归档→提问一条龙 + 本地可控 + 可定制**,而且本体是一个自己会拿主意的 agent。

## 1. 骨架(已验收;2026-10-07 核心改为 agent 循环)

**形态**:本地一体小应用。窗口 = 本地网页(浏览器打开 `localhost`),三个标签页:**课件助手 / 下载管家 / 设置**;另有终端聊天口(Win 交付带的黑窗口,同一套循环)。前端只管显示和交互,真正的活在后端(Python 本地服务)。

**分层**:

```
┌────────────────────────────────────────────────────┐
│  浏览器窗口(localhost) / 终端                       │
│  [课件助手·对话]  [下载管家·对话]  [设置]            │
└───────────────────────┬────────────────────────────┘
                        │ HTTP(仅本机)
┌───────────────────────▼────────────────────────────┐
│  本地服务(Python)                                   │
│  ┌──────────────────────────────────────────────┐  │
│  │  小灶本体 = agent 循环                        │  │
│  │  你说话 → 模型思考 → 调工具 → 看结果 → 继续…… │  │
│  │  步数有上限;每一次模型调用都记账              │  │
│  └──────┬────────────────────────────┬──────────┘  │
│         │ 课件工具族                  │ 下载工具族   │
│  ┌──────▼─────────────────┐   ┌──────▼───────────┐ │
│  │ 列课件 / 翻页 / 看图 /  │   │ 侦察 / 下载      │ │
│  │ 全书找词               │   │ yt-dlp·gallery-dl│ │
│  │ PyMuPDF · 视觉 · 缓存  │   │ 限速 · 归档       │ │
│  └────────────────────────┘   └──────────────────┘ │
└────────────────────────────────────────────────────┘
                        │
          data/(课件、缓存、下载、配置、账本、日志)
```

**设计原则**:

- **判断交给模型,体力活留给代码**:翻哪页、看不看图、用哪把铲子——模型定;抽字、渲染、限速、缓存、记账——工具里写死。
- **工具有硬边界**:护栏(限速、触线即停)写死在工具实现里,模型绕不过。
- **一次提问 = 一次循环**:一次提问可能翻十几页、看几张图,期间多次调用模型;全过程在界面上可见(「正在翻第 7 页」「正在看第 11 页的图」),每次调用都记进账本。

## 2. 课件助手(2026-10-07 改为 agent 形态)

### 形态

丢进 PDF → **直接提问**。「解析」按钮撤销:小灶在回答你的过程中自己翻页、自己决定看不看图。

### 工具族(模型手里的家伙什)

| 工具 | 干什么 | 花钱吗 |
|---|---|---|
| `list_coursewares` | 列出手里的课件(id、名字、页数、看过多少页) | 免费 |
| `courseware_info` | 某份课件的情况:页数、哪些页没有文字层(扫描页) | 免费 |
| `read_page` | 读第 N 页的文字层,结果落缓存 | 免费 |
| `see_page` | 把第 N 页渲染成图,交视觉模型转写成 Markdown,结果落缓存 | **花钱(视觉模型)** |
| `find_pages` | 全书找关键词,返回命中页码——不把整本塞进上下文 | 免费 |

### 与旧管线的对应

- 文字层抽取、扫描页渲染、视觉转写、逐页落盘与哈希缓存——**代码全部保留**,成为 `read_page` / `see_page` 的内层(逐页缓存本身就是"续":看过的不重看)。整本批处理那套(任务状态机、断点续传)不再需要,随旧流程一并撤销。
- 废除:「字数少于 20 字 = 扫描页 → 自动送视觉模型」(实测把只有 16 字的封面页也送去花了钱)、「每次提问把整本 20 万字语料塞进上下文」。
- 新规矩:一页有没有文字层,如实告诉模型;看不看图,**模型自己决定**。看过就落缓存,反复提问不重复花钱。
- 上传流程不变:拖文件进来 → 按内容哈希入库(同一份重复传不会重复存、不重复花钱)。

### 回答规矩(写进小灶的系统提示)

- 答案带页码引用(「第 12 页」),便于朋友翻原课件核对。
- 不确定的内容先翻页再说话,不许编造。
- 扫描页的内容,只在真的看过之后才引用。

### 模型选型(Provider 适配器层)· 按"澳门可用"修订

所有平台走 **OpenAI 兼容接口**,换 `base_url` 即可切换;模型名、接口地址、价格全写进配置文件,不动代码。
**新增硬要求:必须支持工具调用(tool calling)**——agent 形态下这是入场券;「测试连接」会替朋友把这条验掉(见 §4)。

**已实证**:DeepSeek `deepseek-flash` 支持工具调用(2026-10-07 探针实测:拿到问题会先"翻前几页找相关章节",一口气并行调 5 次翻页工具,再引用页码作答)。探针脚本 `tools/probe_tool_call.py` 留在仓库,给朋友选平台时逐家实测用。

**模型有两格配置**:主模型(对话 + 调工具)+ 视觉模型(看扫描页)。视觉那格留空 = 跟主模型同一档;填了就用它——像 Z.ai"文本免费 + 视觉免费"两个档位的组合,正好一格一个。

**三条硬前提(2026-10-06 已核实)**:

- **Google Gemini API 和 Anthropic Claude API 的官方可用地区名单都不含澳门**(官方页面逐条核对,高置信)——光有 Google 账号没用,**这两家直接排除**;OpenAI 官网本次没能核实(全被拦),不作为依赖。
- 大陆版平台(百炼大陆站、智谱大陆站等)注册要大陆手机号 + 实名——对澳门朋友是硬门槛,绕开,**用它们的国际版**。
- 他的支付条件:支付宝 / 微信(澳门)有,国际信用卡没有 → 优选支持扫码充值的。

**三级路线(起步零成本 → 主力付费 → 备选)**:

| 阶段 | 平台 | 注册 / 支付 | 关键点 |
|---|---|---|---|
| 起步(零成本) | **OpenRouter**(聚合网关) | 邮箱注册;充值时信用卡 / **支付宝**皆可(收 5.5% 手续费) | 免费模型 16 个(7 个能看图),50 次/天(充过 $10 后 1000 次/天);**任何模型都能读 PDF**(官方代解析,含扫描件);免费档要逐模型实测 tool calling |
| 起步备选(零成本) | **Z.ai**(智谱国际版) | 邮箱注册;支付方式待核实 | **GLM-4.6V-Flash 视觉模型完全免费**;GLM-4.7-Flash 文本免费;GLM-OCR 仅 $0.03/M;tool calling 支持待实测 |
| 主力(付费,中文最强) | **Kimi 国际版**(platform.kimi.ai) | 邮箱注册;**微信 / 支付宝扫码,$1 起充** | kimi-k3 原生视觉 + 1M 上下文($3/$15);kimi-k2.6 $0.95/$4;**PDF 解析 API 暂时免费**(≤100MB,转 Markdown);充 $5 送 $5 券;限速按累计充值分档($1 档 = 3 次/分钟,单人用够) |
| 主力备选(付费,最便宜) | **阿里百炼国际版** | 阿里云国际账号;支付待核实 | qwen3.8-flash / omni-flash **$0.15 / $0.47**(omni 支持图像+视频输入);新加坡区首送 100 万 token / 90 天 |
| 其他备选 | DeepSeek / MiniMax 国际 | 支付待核实 | DeepSeek 错峰 $0.15/$0.60、有视觉(仅图片,不支持 PDF 直传)、**tool calling 已实证**;MiniMax M3 $0.30/$1.20 |

**推荐路径**:先用已实证 tool calling 的 **DeepSeek**(dev 侧现成;澳门支付方式待核实),或逐模型实测过工具调用的 **OpenRouter 免费视觉模型**,把工具跑通;确认好用后,主力换 **Kimi 国际版**(中文课件最稳、支付最顺)或**百炼国际 qwen3.8-flash**(最便宜)。中文课件支持度(调研判断):Kimi ≈ Qwen > Z.ai > DeepSeek > 国外模型。

**平台自带解析作兜底**:OpenRouter 任意模型读 PDF、Kimi file-extract 免费——可用于特殊情况;**主路仍是本地解析**(省钱、页码引用、可缓存)。

**费用口径**:agent 形态下一次提问 = 多次模型调用(翻页循环),账本逐次记录,真实成本可核。免费额度(OpenRouter 50 次/天、Z.ai 免费模型、百炼新加坡 100 万 token)按"能白嫖就白嫖"用,但**做预算不计入**,以注册后控制台实际为准。付费量级:每周 100 问约 **每月几美元**(估算,循环的多次调用已计入);里程碑 3 用真实用量出**实测账单**。

## 3. 下载管家(2026-10-07 改为 agent 形态)

### 两把铲子,注册成工具

| 工具 | 干什么 |
|---|---|
| `scout_video` / `scout_gallery` | **侦察**:先看清楚这条链接里有什么(标题、条目列表、格式、大小、清晰度)——不开盲盒 |
| `download_video` / `download_gallery` | 真下载:yt-dlp 管 1800+ 视频站(含 B 站、YouTube 等境外站;最新稳定 2026.09.28),gallery-dl 管 1400+ 图集站(含 Pixiv、X;**主仓库在 Codeberg**;最新 1.32.15) |
| `download_file` | 直链下一个文件(比如你手里就有图片的直链) |
| `list_downloaded` | 看看下载目录里已经有什么 |

**没有分派表**:模型侦察完自己挑铲子——哪个站用哪个,它比表格懂得多。参数只给安全枚举(画质:best / 1080p / 720p / 仅音频;范围:第几集到第几集、第几张到第几张),不让模型手写引擎参数。

### 流程

贴链接 → 小灶侦察、把"里面有什么"报给你 → 你说要哪些(一开始就说"全下"也行,它照办)→ 它下载、按站点/批次归档 → 汇报落到了哪。要不要先停下来问你,由它按你的话判断(默认:侦察后先汇报,大批量先确认)。带进度、断点续传;失败的单独列出并写明原因。

### 护栏(写死在工具里,不给绕)

- 下载间隔 1~3 秒、同站并发 1、被限流(429)自动退避。
- 撞上付费墙 / 加密封装(DRM)/ 登录墙 / 个人隐私数据 → **立即停**,提示人工处理。
- 只存本地;**不提供"分享/导出"功能**。
- 以朋友粘贴的那一页为界,不游荡抓站。

### 学校网课平台

拿真实链接**逐个实测**:能下的下;要登录的,用引擎自带的"复用浏览器登录状态"来拿他本来就有权看的内容;加密封装的不碰(付费墙 / DRM 这条线固定不越)。

### 补位

临时存一两张图,浏览器插件更快(Fatkun / Imageye 之类,Chrome / Edge 商店均可)。工具负责的是"批量、成套、多页"。

## 4. 工程与交付(已验收 · 按 Mac 目标修订)

### 语言:Python

四大主力轮子——yt-dlp、gallery-dl、PyMuPDF、MinerU(可选 OCR 层)——全是 Python 生态的现成品,换任何语言都等于重写。对用户(Java 方向)不亏:Python 项目结构简单,这里看到的"怎么组织一个程序"在 Java 里是通的。

### 目标平台与运行时

- **一号目标:朋友的 Mac**(macOS;Apple Silicon 还是 Intel 待自检确认——影响打包架构和 OCR 层取舍)。
- **二号目标:你的 Windows 11**(开发机、自测、备用)。代码从第一天起就按跨平台写。
- **Mac(一号目标)的 Python 运行时用 python-build-standalone**(Astral 维护):分 arm64 / x86_64 两个包(**没有 universal2**,按架构发);它自带 ad-hoc 签名,这是 Apple Silicon 上能跑起来的前提。**Windows 已交付的路线是 PyInstaller 单文件**(`小灶.exe`,CI 自动出包)——两条路线各自成熟,不必强行统一。
- Python 版本取 **3.12 或 3.13**(PyMuPDF 要 ≥3.10;MinerU 要 <3.15)。
- 依赖直接装进自带 Python 的 site-packages,**不用 venv**(venv 路径写死,搬机即废)。

### 目录结构(程序与数据分离)

```
xiaozhao/
├─ app/            程序代码(更新时整包覆盖)
├─ python/         随包自带的 Python(朋友无需自装)
├─ bin/            ffmpeg / ffprobe(静态单文件,yt-dlp 合并音视频用)
├─ data/           数据,更新时一张不丢
│   ├─ courses/    课件 PDF(入库后的原件)
│   ├─ cache/      解析缓存(逐页 Markdown + 页面图)
│   ├─ downloads/  下载的资料(按站点/批次归档)
│   ├─ config.json 配置文件(Key、模型名、接口地址、下载目录…)
│   ├─ usage.jsonl 用量账本(每次模型调用记一笔)
│   └─ logs/       滚动日志
├─ start.command   Mac 双击入口
└─ 启动小灶.bat     Windows 双击入口
```

建议朋友把整个文件夹放在**主目录**(如 `~/xiaozhao`):桌面 / 文稿 / 下载这三个目录受 macOS 权限保护,容易弹框。

### 分发与安装(Mac 优先)

- 出包格式 **tar.gz**,且**必须在 Git Bash 或 macOS 上打**:Windows 的「压缩文件夹」会丢掉可执行位,解出来双击直接废(**已在开发机实测**;tar 打包已验证保得住权限位)。
- 首选安装方式:**给朋友一条 `curl … | tar xz` 命令**——这样下载的文件不沾 macOS 隔离属性,大概率零弹窗直达可用(隔离属性行为由真机清单最终确认,见 §6);浏览器下载作兜底。
- **Gatekeeper(已核实)**:macOS Sequoia 起,右键「打开」不能再绕过拦截;Apple Silicon 上未签名代码一律拦。python-build-standalone 自带的 ad-hoc 签名是钥匙——**别改包内文件、别重新打包**,一改签名就废。万一被拦:系统设置 → 隐私与安全性 →「仍要打开」。
- 服务**只绑 `127.0.0.1`**:回环不触发 macOS 本地网络权限,且从终端启动的进程天然放行。

### 启动器

- **Mac `start.command`**:`cd "$(dirname "$0")"` 锚定路径 → 用自带的 Python 拉起服务 → `open` 浏览器 → `trap` 兜底清理;出错时停住窗口(不然一闪而过,朋友什么也看不到);关终端窗口即退出。记得 `chmod +x`。
- **Windows(已交付,2026-10-07)**:双击 `小灶.exe`(PyInstaller 单文件)或 `启动小灶.bat` → **黑窗口就是聊天界面**(多轮对话;窗口别关,关了就退出),网页版随时可用;exe 认得自己旁边的 `data/`。CI(build-windows)自动出包。`.vbs` 已被微软弃用,不用它。
- 子进程加 `CREATE_NO_WINDOW`,避免调 yt-dlp / ffmpeg 时黑框乱闪。

### 依赖与网络

- 构建期:Python 运行时与 ffmpeg 都从 GitHub Release 下载(URL 固定、可脚本化);ffmpeg 用**静态单文件 ffmpeg + ffprobe 一起随包带**(yt-dlp 两个都要)。**不要让朋友装 Homebrew**(要 Xcode 命令行工具、要密码、要等,对非技术用户是单点故障)。
- **yt-dlp、gallery-dl 是 Python 依赖**:装进自带 Python 的 site-packages,并写进 `requirements.txt`;单独更新走「更新.command / 更新.bat」(见下)。
- 运行期:API 直连(他的网络不需要代理);不引入任何运行时外网依赖。

### 首次配置向导

选平台 → 粘贴 Key → **"测试连接"**——验两件事:模型有回应、模型会调工具(tool calling);两件都过才算配置完成。附一份给朋友的 **API 注册指南**(平台、注册步骤、充值方式,可转发;平台选型见 §2)。

### 错误处理与维护

- 所有报错翻译成**人话**(「Key 失效了,点这里重填」,而不是英文栈),同时写滚动日志。
- 401 → 引导重填 Key;断网 → 明确提示;翻页 / 看图失败 → 指出哪一页、说清下一步(重试 / 换视觉模型)。
- **维护链条**:朋友截图 → 发用户 → 转给 Claude → Claude 修 → 用户发版 → 朋友点"检查更新"。
- **两类更新**:整体更新(换 `app/`,数据不动)走更新通道;下载引擎更新(yt-dlp 因站点改版经常要更新)用一个「更新.command / 更新.bat」跑 `pip install -U yt-dlp gallery-dl`,不惊动整包。
- **更新通道**:托管放 GitHub Releases 或你的 Ubuntu 服务器(只放包,不跑业务);安装 / 更新都给一条 `curl` 链接。

### 构建与测试策略(开发在 Windows,目标在 Mac)

- 用 **GitHub Actions 的 macos-15 runner** 构建 + 冒烟测试(解包后验证 import 与启动);免费档只有 arm64。若朋友是 **Intel Mac**:免费 CI 出不了 Intel 包,改本地交叉装配依赖——所以先确认芯片(见 §6)。
- Windows 上**测不出**三类问题:隔离属性、Gatekeeper、可执行位——必须由 Mac 真机过一遍(§6 清单)。
- 给朋友准备一份「Mac 自检.command」,首次安装前跑一遍,把输出发你。

### 跨平台代码纪律

- 路径一律 `pathlib`;`open()` 永远显式 `encoding="utf-8"`(Windows 中文机默认 GBK,Mac 是 UTF-8);子进程显式 `encoding="utf-8", errors="replace"`。
- 浏览器用标准库 `webbrowser.open(完整 URL)`。
- 入口包 `if __name__ == "__main__":`(macOS 多进程是 spawn 模式)。
- 日志与缓存写进 App 自己目录,不碰 `~/Library` / `%APPDATA%`。
- 就这四条最要命,从第一行代码起执行。

### 可选 OCR 层(MinerU)的取舍

- 只在 **Apple Silicon + macOS 14 以上**可行;Intel Mac 直接放弃(torch 已无 Intel Mac 轮子)。
- 依赖重(57 个包,模型 GB 级,包体会从 ~150MB 涨到 GB 级)——**v1 不装,只留接口**;将来真需要再给他单独加。

### A/B 衔接

下载完的 PDF,直接丢给课件助手(拖进上传框,或从下载列表一键入库)——不让"下载"和"提问"成为两个孤岛。

## 5. 验收方式(2026-10-07 按 agent 形态修订)

分五步交付,每步一条能亲手过的**通过线**;不搞最后一次性开箱。

| 里程碑 | 材料 | 通过线 |
|---|---|---|
| **M1 装得上**(两条腿)· 已过 | 你的 Win + macos CI | Win:双击 → 浏览器自动打开 → 向导填 Key → "测试连接"通过。Mac(CI 冒烟):包解出来(权限位在)能启动;"零弹窗、零拦截"只有真机能验,整条挪到 M5 |
| **M2 课件管线**(已实施,验收并入 M3) | 你手上的模拟课件 | 逐页缓存 / 视觉转写 / 账本 / 服务代码已就位、终版评审已过;原"固定管线"通过线作废,与真课件验收一起并入 M3 |
| **M3 小灶会干活**(agent 循环 + 课件工具) | 朋友的真实课件:文本型 + 扫描件各一份 | 提 5 个问题,≥4 个页码引用正确;**它自己决定**翻哪些页、哪几页要"看图",不靠字数门槛;同一个问题问第二遍,看过的页不重复花钱(账本可核);一次提问花了多少次调用、多少 token,界面上看得见 |
| **M4 下载工具**(两把铲子 + 侦察) | 朋友常逛站点 3~5 条真实链接(含境外站) | 它自己侦察、汇报"里面有什么"(与实际一致);下载的文件能打开;限速与断点续传有效;给一条付费墙 / 登录墙链接 → 明确停下说人话,不硬闯 |
| **M5 给朋友装(Mac 真机)** | 朋友本人 + 他的 Mac | `curl` 一条命令装好、零 Gatekeeper 弹窗;Mac 自检清单全过;向导走通;一页操作卡 + API 注册指南;试用一周,卡壳处记录返修 |

**补充**:

- **成本实测**:M3 时记录 API 真实返回的用量,出"实测月费",替掉估算数(agent 循环一次提问多次调用,账本逐次记)。
- **模型入场实测**:给朋友选平台时,逐家跑 `tools/probe_tool_call.py`;不支持 tool calling 的模型直接排除(「测试连接」也会替朋友验这一条,见 §4)。
- **故意搞破坏**:断网、填错 Key、删一半缓存——报错必须是"人话"。这条不过不算完。
- **Mac 真机专项**:隔离属性 / Gatekeeper / 可执行位 / 防火墙弹窗——Win 上永远测不出,必须在 M5 真机过一遍(清单见 §6)。
- **节奏**:每步先交用户,用户过通过线,再给朋友;用户随时能喊停。

## 6. 动手前必须确认/复核的清单

**向朋友要的材料**:

1. 真实课件 PDF:文本型 + 扫描件各一份。
2. 常逛站点链接 3~5 条(可含境外站,如 YouTube / Pixiv / X)。
3. **Mac 自检输出**(我们打包一份「Mac 自检.command」让他跑):芯片(Apple Silicon / Intel)、macOS 版本——决定打包架构、MinerU 可行性与 Gatekeeper 路径。

**动手前复核**:

4. LLM 平台复核(§2 表里标"待核实"的,开用前逐条验证):OpenRouter 注册是否要手机号、支付宝在真实收银台是否可用;Kimi 国际版充值页在澳门 IP 下是否正常显示微信 / 支付宝;Z.ai、百炼国际、DeepSeek、MiniMax 的支付方式。**外加:各平台拟用档位的 tool calling 支持(用 `tools/probe_tool_call.py` 逐家实测)**。
5. **Mac 真机实测(Win 上测不出)**:浏览器下载 → 解压 → 双击 .command 到底发生什么;被拦时「仍要打开」按钮是否出现;`xattr -dr` 后是否恢复;`curl | tar` 路径是否真零弹窗;绑 127.0.0.1 的服务是否弹防火墙;关窗后进程是否退出。
6. 各平台文件接口口径以调用当天文档为准(扫描件 PDF 走视觉模型还是文件接口、体积限制)。

**已在开发机实测的结论(可当事实用)**:

- Windows「压缩文件夹」/Compress-Archive 打包会丢可执行位,Git Bash `tar` 保得住。
- VBScript 已被微软标记弃用(当前 Win11 仍内置可用,但不是长期方案)。
- **DeepSeek `deepseek-flash` 支持 tool calling**,且会一轮并行发多个工具调用(2026-10-07 探针实证)。

**已被复核否定的说法(不要再用)**:

- DeepSeek 旧价(V4-Flash 1.5/4.5 那版)——已被 2026-09-10 新价替代。
- MinerU「最新稳定是 3.4.5」——4.0 已于 2026-09-16 发布。
- gallery-dl「GitHub 是完整主仓库」——主仓库与 issue 均在 Codeberg。
- 「右键打开可以绕过 Gatekeeper」——Sequoia 起已取消。
- 「有 Google 账号就能用 Gemini API 白嫖」——官方可用地区名单不含澳门(2026-10-06 官方页核实),此路不通。
