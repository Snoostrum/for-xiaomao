# 小灶 · 设计文档

> 给一位不太了解 AI 的朋友做的个人工具:**PDF 课件问答 + 资料批量下载**。
> 跑在他自己的电脑上(默认 Windows,中国大陆网络、无代理)。
> 状态:五节设计已逐节验收通过,本文为书面定稿版,待书面审阅。
> 项目目录 `xiaozhao`(界面显示名「小灶」)。目录名用英文,避开中文路径在打包工具链里的偶发问题。

---

## 0. 背景、目标与边界

**朋友画像**:不太了解 AI,但电脑上"会折腾"。

**两大用途**:

- **A 课件助手**:把 PDF 课件丢给 AI 提问、总结。课件多为中文 PPT 导出,可能含扫描页。
- **B 下载管家**:批量获取高清资料 = 高清图片/素材 + 视频/录播课。

**成功标准**:

1. 朋友在无代理环境下一次装成、一次配通。
2. 课件问答页码引用正确,扫描页读得出;同一个课件解析只跑一次、不重复花钱。
3. 下载只读他本来就有权访问的公开内容;触线即停。
4. 月费可见可控(量级 5~30 元,以实测为准)。

**分工**(本项目特例):Claude 全权编写,用户验收。代码需可读、带解释,用户能看懂结构并自行修改。

**明确的边界(不做)**:

- 不绕付费墙、验证码、DRM、加密封装;不抓个人隐私数据。
- 网盘分享不做自动化,只识别并提示用官方客户端。
- 境外站点默认不做(朋友无代理环境直连不了);是否例外取决于朋友的实际情况(见 §6)。
- 不做多用户、在线服务、手机端;不做"分享/导出"功能。

## 1. 骨架(已验收)

**形态**:本地一体小应用。窗口 = 本地网页(浏览器打开 `localhost`),三个标签页:**课件助手 / 下载管家 / 设置**。前端只管显示和交互,真正的活在后端(Python 本地服务)。

**分层**:

```
┌────────────────────────────────────────────────┐
│  浏览器窗口(localhost)                         │
│  [课件助手]  [下载管家]  [设置]                  │
└───────────────┬────────────────────────────────┘
                │ HTTP(仅本机)
┌───────────────▼────────────────────────────────┐
│  本地服务(Python)                               │
│  ┌──────────┐  ┌──────────┐  ┌──────────────┐  │
│  │ 课件引擎  │  │ 下载调度  │  │ 配置/日志/更新│  │
│  └────┬─────┘  └────┬─────┘  └──────────────┘  │
│       │             │                           │
│  解析层(PyMuPDF/视觉/OCR)                     │
│                     │                           │
│        ┌────────────┼────────────┐              │
│        │            │            │              │
│     yt-dlp    gallery-dl   自研薄层(网页原图)  │
│     (插件式引擎:加站点 = 加模块,不动主体)      │
└─────────────────────────────────────────────────┘
                │
        data/(课件、缓存、下载、配置、日志)
```

**设计原则**:下载引擎插件式(每个引擎一个独立模块,有统一接口:侦察/下载/进度);解析与问答分离(解析产物落盘缓存,问答随时可换模型)。

## 2. 课件助手(已验收)

### 流程

**入库 → 解析(三层)→ 问答 → 缓存**

### 解析(三层,从便宜到贵)

1. **本地文本层(PyMuPDF)**:逐页抽文字,带页码。文本型 PDF 到这层结束,**不花一分钱**。
2. **视觉层(扫描页兜底)**:某页没文字或文字极少 → 判定为扫描页 → 渲染成图片 → 发给视觉模型读。
3. **MinerU 兜底(离线,可选装)**:排版特别复杂、前两层效果都不行时使用。v1 预留接口,可以先不装。
   - 注意:MinerU 4.0 已于 2026-09-16 发布(档位制);若用 3.x 纯 CPU 必须显式加 `-b pipeline`,否则默认会下载约 2GB 权重并在 CPU 上推理,极慢。

### 问答

- 单份课件 ≤150 页:**不做 RAG**,全文进长上下文,直接问。
- 答案**必须带页码引用**(「第 12 页」),便于朋友翻原课件核对。
- 跨课件检索(如"所有课件里哪份讲过这个")才考虑 RAG——后续版本,不在 v1。

### 缓存

**解析只跑一次**:按文件内容哈希缓存为逐页 Markdown + 页面图片。同一个课件重复提问直接用缓存,不重复解析、不重复花钱。

### 模型选型(Provider 适配器层)

所有平台走 **OpenAI 兼容接口**,换 `base_url` 即可切换;文件上传/OCR 等专有接口单独适配。**模型名、接口地址、价格全部写进配置文件,不动代码**(国内模型名几个月一换)。

| 角色 | 首选 | 备选 |
|---|---|---|
| 文本问答 | 阿里百炼 qwen-plus | DeepSeek V4-Flash;GLM-5.3-Flash |
| 看课件截图 | 智谱 GLM-4.6V-Flash(免费) | qwen3-vl-flash |
| 整页/公式 OCR | 智谱 GLM-OCR(公式转 LaTeX) | qwen3.5-ocr |

价格参考(2026-10-06 调研 + 交叉复核,**动手前到控制台复核**):

- qwen-plus:0.8 / 2 元每百万 token(未官方复核)。
- DeepSeek V4-Flash:2026-09-10 起谷时 1 / 4 元、峰时 2 / 8 元,周末全天按谷时(**已复核,较旧数再降**)。
- GLM-4.6V-Flash:免费。
- GLM-OCR:0.2 元/百万 token,PDF ≤100 页。
- qwen3.5-ocr:0.5 / 2 元(注意:其上下文 64K 还是 128K 官方口径冲突,**实现不依赖 128K 这个数**)。
- 免费额度:百炼首开每模型 100 万 token / 90 天(未复核);智谱有若干免费模型。**做预算不得计入免费额度**,以注册后控制台实际余额为准。
- 成本量级:每周 100 问约 **5~30 元/月**(估算);里程碑 2 用真实课件的 API 用量出**实测账单**。

**诚实定位**:豆包 PC / 腾讯 ima / 夸克已覆盖部分课件问答需求。本工具的价值 = **下载→归档→提问一条龙 + 本地解析可控 + 可定制**。

## 3. 下载管家(已验收)

### 总策略:不造爬虫,造调度

| 来源 | 用什么 | 说明 |
|---|---|---|
| 视频站 | **yt-dlp** | 1800+ 站点(含 B 站),高频更新;最新稳定 2026.09.28 |
| 图集/画廊站 | **gallery-dl** | 1400+ 站点;**主仓库已迁 Codeberg**,新模块只在那边加;最新 1.32.15 |
| 普通网页里的图 | **自研薄层** | 页面 → 找原图地址(缩略图命名规律 / 页面内嵌 JSON / 签名 URL)→ 按分辨率筛高清 → 去重 → 限速下载 |
| 网盘分享 | **只识别,不自动化** | 识别到分享链接 → 提示用官方客户端最稳最快 |

### 流程

粘链接 → **侦察**(先列出里面有什么:标题、格式、大小、清晰度——不开盲盒)→ 勾选 → 下载 → 按站点/批次归档、重名去重。带进度条、断点续传;失败的单独列出并写明原因。

### 护栏(写死在代码里,不给绕)

- 下载间隔 1~3 秒、同站并发 1、被限流(429)自动退避。
- 撞上付费墙 / 加密封装(DRM)/ 登录墙 / 个人隐私数据 → **立即停**,提示人工处理。
- 只存本地;**不提供"分享/导出"功能**。
- 以朋友粘贴的那一页为界,不游荡抓站。

### 学校网课平台

拿真实链接**逐个实测**:能下的下;要登录的,用官方自带的"复用浏览器登录状态"来拿他本来就有权看的内容;加密封装的不碰(绕过技术防护在国内有刑责判例,这条线不越)。

### 补位

临时存一两张图,浏览器插件更快(Fatkun / Imageye 之类,大陆装 **Edge** 商店版)。工具负责的是"批量、成套、多页"。

## 4. 工程与交付(已验收)

### 语言:Python

四大主力轮子——yt-dlp、gallery-dl、PyMuPDF、MinerU——全是 Python 生态的现成品,换任何语言都等于重写一遍。对用户(Java 方向)不亏:Python 项目结构简单,这里看到的"怎么组织一个程序"在 Java 里是通的。

### 目录结构(程序与数据分离)

```
xiaozhao/
├─ app/            程序代码(更新时整包覆盖)
├─ runtime/        内嵌 Python(朋友无需自装)
├─ data/           数据,更新时一张不丢
│   ├─ courses/    课件 PDF(入库后的原件)
│   ├─ cache/      解析缓存(逐页 Markdown + 页面图)
│   ├─ downloads/  下载的资料(按站点/批次归档)
│   ├─ config.json 配置文件(Key、模型名、接口地址、下载目录…)
│   └─ logs/       滚动日志
└─ 启动小灶.vbs     双击入口(拉起服务 → 自动开浏览器)
```

### 安装与打包

- 内嵌精简版 Python(embeddable),**朋友无需自装 Python**。
- **不用** PyInstaller `--onefile`(杀毒误报重灾区,尤其 360);用 `--onedir` 或纯目录 + 启动脚本。
- 依赖全程国内源:Python 包走清华 PyPI 镜像;OCR 模型走魔搭(ModelScope)。**没有任何一步需要代理**——硬指标。
- 待确认:朋友的 Windows 版本/位数、是否装 360 或电脑管家(影响打包与杀毒加白,见 §6)。

### 首次配置向导

选平台 → 粘贴 Key → **"测试连接"**(通过才算配置完成)。附一份给朋友的 **API 注册指南**(选平台、实名、充值、建 Key,可转发)。

### 错误处理与维护

- 所有报错翻译成**人话**:「Key 失效了,点这里重填」,而不是一串英文栈;同时写滚动日志。
- 401 → 引导重填 Key;断网 → 明确提示;解析失败 → 指出哪一页、建议哪条路(换视觉模型 / 上 MinerU)。
- **维护链条**:朋友截图 → 发用户 → 转给 Claude → Claude 修 → 用户发版 → 朋友点"检查更新"。
- **更新通道**:用户的 Ubuntu 服务器只放一个"版本号文件 + 更新包",工具里做"检查更新";不跑业务、不占资源。退路:每次给用户一个压缩包转发。

### A/B 衔接

下载列表里的 PDF,提供"**送去课件助手**"按钮,一键入库——不让"下载"和"提问"成为两个孤岛。

## 5. 验收方式(已验收)

分四步交付,每步一条用户能亲手过的**通过线**;不搞最后一次性开箱。

| 里程碑 | 材料 | 通过线 |
|---|---|---|
| **M1 装得上**(先在一台自己的电脑) | — | 双击 → 浏览器自动打开 → 向导填 Key → "测试连接"通过 |
| **M2 课件助手能答** | 朋友的真实课件:文本型 + 扫描件各一份 | 20 页课件提 5 个问题,≥4 个页码引用正确;扫描页文字/公式可读;同课件重复提问不重复解析、不重复花钱 |
| **M3 下载管家能下** | 朋友常逛站点 3~5 条真实链接 | 侦察列表与实际一致(标题/大小/清晰度);限速与断点续传有效;给一条付费墙链接 → 明确停下提示,不硬闯 |
| **M4 给朋友装** | 朋友本人、他无代理的电脑 | 装成功、向导走通;交付一页操作卡 + API 注册指南;试用一周,卡壳处记录返修 |

**补充**:

- **成本实测**:M2 时记录 API 真实返回的用量,出"实测月费",替掉估算数。
- **故意搞破坏**:断网、填错 Key、删一半缓存——报错必须是"人话"。这条不过不算完。
- **节奏**:每步先交用户,用户过通过线,再给朋友;用户随时能喊停。

## 6. 动手前必须确认/复核的清单

**向朋友要的材料**:

1. 真实课件 PDF:文本型 + 扫描件各一份。
2. 常逛站点链接 3~5 条。**特别确认:含不含境外站**(YouTube / Pixiv / X 等)——无代理直连不了,有则面向他的方案要重估。
3. 设备画像:Windows 版本、是否装 360/电脑管家、内存与显卡(影响本地 OCR 可行性与打包方式)。

**动手前复核**:

4. 各平台价格、模型名到控制台逐条复核;免费额度以注册后实际余额为准。
5. 无代理连通性:装机第一个小时,实测各家 API 域名直连稳定性。
6. 两处接口口径以调用当天文档为准:通义文件接口对扫描件 PDF 的体积限制(20MB 还是 150MB)、智谱文件接口新旧口径。

**已被复核否定的说法(不要再用)**:

- DeepSeek 旧价(V4-Flash 1.5/4.5 那版)——已被 2026-09-10 新价替代。
- MinerU「最新稳定是 3.4.5」——4.0 已于 2026-09-16 发布。
- gallery-dl「GitHub 是完整主仓库」——主仓库与 issue 均在 Codeberg。
