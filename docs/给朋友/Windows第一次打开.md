# 小灶 · Windows 第一次打开

## 一、双击后可能跳出一块蓝色提示,别慌

「Windows 已保护你的电脑」——因为小灶是个人做的小工具,没有买微软的数字签名(签名要公司和钱)。
它没有病毒,两下点过去就行:

1. 点蓝框里的「**更多信息**」
2. 再点右下角出现的「**仍要运行**」

以后每次换新版,可能还会问一次,同样两下。

## 二、打开后你会看到两个窗口

| 窗口 | 是什么 |
|---|---|
| 黑窗口 | **聊天版**:直接打字,回车发出去;输入「退出」结束 |
| 浏览器窗口 | **网页版**:填 API Key、以后放课件、下载资料都在这里 |

两个都别关——关了,对应的功能就停了。想全部退出:黑窗口输入「退出」,再把窗口关掉。

## 三、第一次用:先填 Key

1. 在浏览器窗口打开「**设置**」页
2. 把 API Key 粘进去,点「**保存**」
3. 再点「**测试连接**」,看到「连接成功」就齐了
4. 回到黑窗口,随便打句话试试

## 四、想挪个地方 / 带给别人

把小灶.exe 和它旁边的 **data 文件夹**一起拷走就行。
Key 存在 data 里,跟着走——换台电脑放同样的位置,打开就能用。

小建议:放在**桌面**,或自己建的文件夹里。别放 C:\Program Files 这类系统目录——那里没权限让 data 跟着存。
